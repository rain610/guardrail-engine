```md
## 代码门禁（AgentGuard，必做）

本机装了统一代码门禁 harness（工程根见 `AGENTGUARD_DIR`，旧名 `HARNESS_DIR` 兼容；或 `~/.agentguard/harness.path`）。

改完任意 AgentGuard 客户×三端仓库（PC / H5 / .NET 后端）的代码后，**在改动仓库根目录**执行：

```sh
python <HARNESS>/harness/agents/auto-gate.py
```

退出码语义：

| 退出码 | 含义 | 你该做什么 |
|---|---|---|
| 0 | 通过 | 正常继续 |
| 1 | 拦住（有阻断级问题） | 按输出里的 FIX 提示改到通过后**重跑**；不要 `--no-verify` 绕过、不要为过门禁改业务逻辑 |
| 2 | 门禁配置/环境问题 | 报告用户，别自行改门禁 |
| 3 | 非受管仓库 | 跳过（该仓未纳入门禁） |

两条硬约束：

1. **整文件完成再跑**（别拿半成品跑，避免误报）；
2. 若某处确实是合规写法被误报，用行内豁免标记 `harness-ok: <规则ID> <理由>`（写在命中行或紧邻上一行），**不要**删规则或全局关规则。
```
