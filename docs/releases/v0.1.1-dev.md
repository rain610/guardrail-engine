# agentguard 内部安装包 · v0.1.1-dev（2026-09-14）

> 内部试用版（仅限公司内部使用，请勿外发）。

## 包内容
- `agentguard-0.1.1.dev0-py3-none-any.whl` —— CLI + MCP 薄服务（`pip install` 后得到 `agentguard` 命令）
- `marketplace/` —— Claude Code / OpenClaw 插件市场 bundle（技能 + MCP，一次装齐）
- `fix_paths.py` —— 换机器路径适配（把包内配置改到你的 python / 引擎路径，一条命令）
- `安装说明.md`（含「五、升级」）/ `OPENCLAW.md` / `LICENSE` / `SHA1SUMS.txt`

## 本版变化（相对 v0.1.0-dev）
- 新增 `fix_paths.py`：换机器不再需要手工改 `.mcp.json`（打包机路径一键适配）
- 安装说明新增「第 0 步·路径适配」与「五、升级」（旧包 → 新包替换步骤）
- README「三种接入方式」细化为「最短路径 + 三通道逐步安装」（照着做即可）
- 仓库侧工具同步：本机对账 `sandbox/audit_reconcile.py`、并行测试 `sandbox/run_tests.py`（维护用）

## 安装（两步）
1. 解压 → `python fix_paths.py --harness <你的 agentguard 路径>`
2. 按 `安装说明.md` 安装（CLI / Claude 插件 / OpenClaw 任选）
