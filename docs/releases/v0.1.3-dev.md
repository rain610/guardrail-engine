# agentguard 内部安装包 · v0.1.3-dev（2026-09-18）

> 内部试用版（仅限公司内部使用，请勿外发）。
> 这是**功能档 + 修复档**：新增可区分「跳过 / 被削弱」的台账字段、升级与卸载两条链路的补齐、
> 以及 README 面向同事的三节（能带来什么 / 升级 / 卸载）。**无破坏性变更**，可直接覆盖安装。

## 包内容
- `agentguard-0.1.3.dev0-py3-none-any.whl` —— CLI + MCP 薄服务（`pip install` 后得到 `agentguard` 命令）
- `marketplace/` —— Claude Code / OpenClaw 插件市场 bundle（技能 + MCP，一次装齐）
- `fix_paths.py` —— 换机器路径适配（一条命令改到你的 python / 引擎路径）
- `upgrade.py` —— 升级入口（v0.1.2 起新增：按你的布局给出该执行的动作，不猜）
- `uninstall.py` —— 一键卸载（默认预演、`--yes` 执行；五项逐项撤回，可逆 + 台账留痕）
- `安装说明.md`（含「四、卸载」「五、升级」）/ `OPENCLAW.md` / `LICENSE` / `SHA1SUMS.txt` / `PACK-INFO.json`

## 本版变化（相对 v0.1.2-dev）

### 同事能直接感觉到的
- **README 补三节**：「能带来什么」「升级」「卸载」。此前 README 讲了「是什么 / 怎么装」，
  却漏了最要紧的三问 —— 用了它对我有什么好处、装完怎么升级、不想要了怎么退干净。
- **升级链路补齐**：新增 `upgrade.py`；pip 已装同版本号时**不再静默**，改为直接代跑
  `--force-reinstall` 再对账（原先同版本号重装会一声不响地什么都不做）。
- **卸载链路补齐**：编辑期 shim 纳入《安装说明》与 `uninstall.py`；skill 归档的
  `.disabled-*` 残留、重名与「占用中」误诊都有了对策。
- **出货件与机器无关**：包内不再残留你本机的绝对路径，`PACK-INFO.json` 带整包指纹 ——
  同一个版本号被打包两次且内容不同时会**当场告警**（v0.1.2-dev 就发生过一次：09-14 与 09-17
  两次打包内容不同，当时无人发现）。

### 维护者能感觉到的
- **台账新增 `skipped` / `weakened`**：「本机把 gate 关了」与「跑了且通过」此前都是 `rc=0`，
  分不开；现在两条削弱路径各留痕（`cli.py log` 加 `mark` 列）。
- **测试套件 `--fast` 快跑档 214.5s → 约 29.8s**（全量 678 例不变）。判据不是「文件名义耗时」，
  而是「这些秒在不在快跑档的关键路径上」+「这条 ≥1s 的例是不是某条变异的唯一判据」。
- **锁清单再基线** 35 个模块 / 506 条 → 43 个模块 / 677 条；给计数看守补上第一条变异 M38。
- **代码评审 v13 全量落地**（严重 1–5 / 高 A·B·6·7 / 中 9–20 / 低 18·24·25），分五批带回归锁。
- **多处「写死的数字」被清掉**：R5 出货提示里那个复现不出来的存量数、以及文档里几处与实况
  对不上的计数 —— 判据是**每个数都要能指到一个当场可跑的命令**。

## 安装（两步）
1. 解压 → `python fix_paths.py --harness <你的 agentguard 路径>`
2. 按 `安装说明.md` 安装（CLI / Claude 插件 / OpenClaw 任选）

## 升级
见 `安装说明.md`「五、升级」—— 路径引用型（`.mcp.json` 指到你 clone 的仓库）**无需处理**，
pull 即可；副本型（按版本目录放的）重跑安装命令，或 `marketplace add <新路径>`。

## 卸载（一步）
包内 → `python uninstall.py --harness <你的 agentguard 路径>`（预演）→ 加 `--yes` 执行。
