# agentguard 内部安装包 · v0.1.2-dev（2026-09-14）

> 内部试用版（仅限公司内部使用，请勿外发）。

## 包内容
- `agentguard-0.1.2.dev0-py3-none-any.whl` —— CLI + MCP 薄服务（`pip install` 后得到 `agentguard` 命令）
- `marketplace/` —— Claude Code / OpenClaw 插件市场 bundle（技能 + MCP，一次装齐）
- `fix_paths.py` —— 换机器路径适配（一条命令改到你的 python / 引擎路径）
- `uninstall.py` —— **一键卸载**（本版新增：默认预演、`--yes` 执行；五项逐项撤回，可逆 + 台账留痕）
- `安装说明.md`（含「四、卸载」「五、升级」）/ `OPENCLAW.md` / `LICENSE` / `SHA1SUMS.txt`

## 本版变化（相对 v0.1.1-dev）
- 新增 `uninstall.py`：同事不想要了可一条命令退干净（技能副本 / 提交期钩子 / Claude 插件 / OpenClaw 扩展 / pip CLI 五项，能自动的自动做，够不着的给现成命令）
- 安装说明「四、卸载」重写为逐项对照表；OPENCLAW.md / RUNBOOK 同步
- 其余与 v0.1.1-dev 相同（fix_paths 路径适配、中文/ASCII 双通道等）

## 安装（两步）
1. 解压 → `python fix_paths.py --harness <你的 agentguard 路径>`
2. 按 `安装说明.md` 安装（CLI / Claude 插件 / OpenClaw 任选）

## 卸载（一步）
包内 → `python uninstall.py --harness <你的 agentguard 路径>`（预演）→ 加 `--yes` 执行。
